# Interpretation guide

HUNTER_Score is a frozen classifier probability for the v1 development task, not a mitochondrial-localization probability.

ABOVE_THRESHOLD means score >= 0.5428662440774465 and should be described as an ncMTS-like sequence-architecture priority.

BELOW_THRESHOLD is non-exclusionary because prospective H5-I sensitivity at the frozen threshold was 0.50.

Localization, submitochondrial compartment and import mechanism require independent evidence.
