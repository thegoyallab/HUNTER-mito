## Description
HUNTER v1 is an interpretable sequence-architecture framework for prioritizing proteins with sequence features associated with presequence-independent/non-classical mitochondrial targeting. The frozen v1 model uses 42 N-terminal descriptors and the immutable operating threshold 0.5428662440774465. The score is a sequence-architecture prioritization measure and is not a mitochondrial-localization probability.
