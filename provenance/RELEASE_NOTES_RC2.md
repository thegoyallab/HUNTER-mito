# HUNTER v1.0.1rc2

RC2 is an interface/documentation release candidate around the unchanged frozen HUNTER v1 scientific core.

Added:
- `hunter describe`
- explicit N30/N60/N100 sequence-representation wording
- four stable explanatory descriptors
- formal output/claim contract
- ncMTS/ncMLS-like interpretation wording
- explicit prohibition on residue-level HUNTER signal claims

Unchanged:
- model file
- 42-feature order
- Stage24H2 feature engine
- scoring core
- frozen threshold
- H5/HPS scientific behavior

Public release remains blocked until a project license is selected and final citation/repository metadata are approved.
