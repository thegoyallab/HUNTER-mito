HUNTER v1 deterministic regression fixture

This 10-record set is preserved from the validated v0.7.22 release as an
end-to-end software regression fixture. It contains five above-threshold and
five below-threshold HPS-v1 exact-match records.

It is NOT a biological validation cohort and is not the public Load example
panel. The public biological example is HUNTER_v1_public_example_5plus5.fasta.
